## 1. 为什么本项目采用 GPL-3.0-or-later

MyScreenDraw 的图形界面构建在 **PyQt6** 之上。PyQt6 由 Riverbank Computing 以
**GPL v3 或商业许可证** 双轨提供，它**不是** LGPL。

因此：

- 若以 GPL 版 PyQt6 构建并分发本程序，本程序必须以 **GPL 兼容** 的方式分发；
- 若希望以闭源或与 GPL 不兼容的许可证分发，则需要向 Riverbank Computing 购买
  **商业 PyQt 许可证**，并可能同时需要商业 Qt 许可证。

本项目选择前者：以 **GPL-3.0-or-later** 开源。具体分发仍须满足各组件的许可义务。

参考：

- PyQt 许可证 FAQ：https://www.riverbankcomputing.com/commercial/license-faq
- Qt 开源许可义务：https://www.qt.io/licensing/open-source-lgpl-obligations

## 3. 构建工具与打包运行组件

### 3.1 PyInstaller

| 项目 | 内容 |
| --- | --- |
| 用途 | 将程序打包为 Windows 便携版可执行文件 |
| 许可证 | GPL v2（含 bootloader 例外条款），部分文件为 Apache-2.0 |
| 主页 | https://pyinstaller.org/ |
| 许可证说明 | https://pyinstaller.org/en/stable/license.html |

PyInstaller 的例外条款允许使用它打包并分发应用，且**不要求**被打包的应用采用
PyInstaller 的许可证，也不要求在应用中致谢 PyInstaller。本项目采用 GPL-3.0-or-later
是出于 PyQt6 的要求，而非 PyInstaller 的要求。

PyInstaller 本身是构建工具，但生成的 EXE 包含 bootloader；应复核其许可和例外条款，不能把它简单标为“没有代码随包分发”。

## 4. 本项目自身代码

项目模块和复核边界见 `docs/architecture.md` 与 `docs/provenance-audit.md`。当前文档不声称已逐行确认全部代码原创或完成 Git 全历史审计。引入外部实现时必须记录来源并保留许可声明。

字体、图标说明：

- 界面图标（如旋转键）由程序运行时用 `QPainter` 绘制，不含第三方图标资源；
- 未内置任何字体文件，界面字体使用系统自带字体（如 Microsoft YaHei / Segoe UI）；
- 代码中使用的少量 Unicode 符号（▲▼×⋯↺⠿🌈）来自 Unicode 标准，不构成第三方素材。

## 6. 复核范围与未覆盖项

版本以 `requirements.lock`、`requirements-build.lock` 和最终包内容为准。本次核对了本机匹配锁文件版本的 PyQt6_sip 13.11.1 许可元数据与 LICENSE，修正了此前误写的 GPL/商业许可；不应将其与 PyQt6 的许可混为一谈。

PyInstaller 包还携带 Python 运行时。其许可、Qt 内含第三方组件的声明以及其他实际捆绑文件，需要在最终分发审查中一并核对。本表不是可替代上游许可证全文的 SPDX/SBOM 清单。

pytest、pytest-subtests 是开发测试工具，当前不在运行时/构建锁文件中；不要仅根据开发环境安装列表判断哪些组件随发行包分发。文档更新不会修改已经发布的 ZIP 内的旧声明，下一次构建才会带入更新文本。
