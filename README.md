# MyScreenDraw

> **English**: [README.en.md](README.en.md)

MyScreenDraw 是一个面向**教室触控大屏**的全屏批注 / 白板 / 数学教学工具：

- 在任意画面上**随手批注**——普通笔、荧光笔、激光笔
- **手绘自动转标准图形**：画完把笔停在末端，笔尖进度环转满即定形；想保留手绘直接抬笔
- **白板多页管理**，黑白板切换，逐页导出 PNG / PDF / SVG / EPS
- **真实毫米刻度的直尺、量角器、三角板**（按屏幕校准），支持实时读数
- **随机点名、计时器、演示聚光灯、计算器**——一节课无需切换任何软件
- **单机离线**：不联网、不上传、无账号，适合课堂与敏感环境

当前版本 **v5.3.4**，界面支持 8 种语言（自动跟随系统）：中文、English（英语）、Français（法语）、Español（西班牙语）、Deutsch（德语）、Русский（俄语）、한국어（韩语）、日本語（日语）。


## 快速开始

1. **获取程序**：解压便携版 `MyScreenDraw` 整个文件夹到桌面、D 盘或 U 盘（免安装，不写注册表）。
2. **启动**：双击 `MyScreenDraw.exe`。程序会在同目录自动创建 `data/`（配置与自动保存）和 `exports/`（导出文件）。
3. **退出**：按 **F12**（全局热键，全屏画布下也有效）。

> ⚠️ 请把程序放在**你有写入权限**的目录（桌面、D 盘、U 盘）。放在 `C:\Program Files` 等受保护目录会因权限不足而无法保存配置和数据。

## 功能一览

### 批注与绘图
- 普通笔 / 荧光笔 / 激光笔（颜色、粗细、透明度可调；激光笔只指示不落墨）
- 橡皮（圆形擦 / 线条擦）
- 图形工具：直线、虚线、三角形、矩形、平行四边形、梯形、菱形、圆、椭圆、角
- 立体图形：正方体、长方体、圆柱、圆锥
- 框选 / 点选，复制、删除、移动、缩放、旋转，撤销 / 重做

### 智能功能
- **停笔定形**：手绘画完，笔停在末端约 0.6 秒即转成标准图形（笔尖有进度环提示）；直接抬笔则保留手绘，永不误触发
- 连画 3 段共线短线自动合成虚线
- 直线端点自动吸附
- 几何辅助构造：外接圆、内切圆、中线、高、对角线、角平分线等

### 白板
- 多页管理，页面缩略图导航
- 黑 / 白板切换
- 逐页导出 PNG / PDF / SVG / EPS（多页导出带页码；SVG/EPS 为矢量，可再编辑）

### 课堂工具
- **测量教具**：真实毫米/厘米直尺、45°/30° 三角板、实时读数量角器（可移动、旋转、调整量程）
- **随机点名**：导入 txt/csv 名单，抽中结果大字全屏投影展示
- **计时器**：正计时 / 倒计时，到点响铃 + 红色闪烁
- **放大镜**、**演示聚光灯**（暗化全屏、亮区跟随鼠标）
- 计算器
- 文字与公式：拖拽定框、多行输入、可改色/粗细/旋转；结构化公式编辑器支持分数、上下标、根号、求和、积分（点哪个格子就在哪输入）。字母数字用系统触摸键盘，符号面板另按类型折叠在键盘上方

### 导入 / 导出
- 导入图片或 PDF（图片与 PDF 页面以 base64 内嵌进项目文件，**单文件自包含**，可分享可备份）
- 导出 PNG / PDF / SVG / EPS
- 支持把 `.msd` / `.json` 项目文件**拖到主面板**直接打开

## 使用说明

### 测量教具校准（重要）
第一次使用直尺前，建议先校准：
「工具 → 辅助作图 → **校准当前屏幕**」，用实体直尺对齐校准窗口的两个端点。校准按显示器分别保存；未校准时使用系统 DPI 估算值。

- 直尺每个小刻度 1 mm、主刻度 1 cm；鼠标悬停尺身可实时读取 mm/cm
- 滚轮或橙色圆形手柄调整尺子**量程**（不改变每毫米实际间距）；拖动紫色方块或 `Ctrl + 滚轮` 调整尺身**宽度**
- 量角器：圆心对准角的顶点、水平基线对准角的一边；悬停半圆内实时读数，按住 Shift 吸附整度
- 教具可拖动本体移动、拖青绿色手柄旋转、**右键移除**

### 穿透模式
点「穿透模式」后，鼠标/触控会穿过画布直接操作下层软件；再点「绘图模式」恢复批注。切换时已画内容不会丢失。

### 项目文件与自动保存
- 「工具 → 打开 / 保存」管理 `.msd` 项目文件（含白板所有页面）
- 程序每 30 秒自动保存；异常退出后下次启动会询问是否恢复
- 主动保存才可靠，自动保存仅用于意外恢复

## 常见问题（FAQ）

**Q：Windows 提示「Windows 已保护你的电脑」/ 杀毒软件报警？**
A：这是 Windows 对**未签名程序**的常规提示，**不代表你的电脑中毒**。点「更多信息 → 仍要运行」即可使用，或用杀毒软件扫描确认——程序是**开源、单机离线**的，不联网、不上传数据。

为什么会提示？因为发行版 exe 还没有做代码签名。要彻底消除它，需要由**发布者（开发者）**购买代码签名证书并给发行版签名——这属于分发信任问题，不是程序安全问题，几乎所有免费/开源桌面软件第一次运行都会遇到同样的提示。如果你不放心，也可以自己从源码构建一份（见 [CONTRIBUTING.md](CONTRIBUTING.md)）。

**Q：数据保存在哪里？**
A：程序目录下的 `data/`（配置、自动保存、点名名单、本地日志）和 `exports/`（导出文件）。备份时请连同 `data/` 一起备份。

**Q：支持多显示器吗？**
A：画布固定在主屏幕；工具栏可在各屏幕间拖动，直尺校准按显示器分别保存，截图/导出可指定目标屏幕。

**Q：EPS 导出后中文显示不全？**
A：EPS 是矢量 PostScript，使用标准字体，不含中文字库的查看器可能缺字。需要矢量且含中文请用 SVG。

**Q：能同时两指/两人一起画吗？**
A：可以（v5.2.0 起）。批注笔和荧光笔支持多指同时书写，每根手指各写一笔、各自独立停笔定形，撤销按「笔完成的先后」逐笔回退。两指共用当前工具和颜色（不能一指画笔、一指橡皮）；选择、图形、文字、橡皮仍是单点操作。

## 隐私与数据安全

- **完全离线**：不联网、不上传任何数据、无更新服务
- 本地日志（`data/events.jsonl`）可能包含文件名等信息，分享前请自行检查
- 点名名单（`data/roster.json`）含学生姓名，属个人信息，请勿随程序分发
