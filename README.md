# MyScreenDraw

> **English**: [README.en.md](README.en.md)

MyScreenDraw 是一个面向**教室触控大屏**的全屏批注 / 白板 / 数学教学工具：

- 在任意画面上**随手批注**——11 种永久笔形，另有荧光笔和激光笔
- **手绘自动转标准图形**：画完把笔停在末端，笔尖进度环转满即定形；想保留手绘直接抬笔
- **白板多页管理**，黑白板切换，逐页导出 PNG / PDF / SVG / EPS
- **真实毫米刻度的直尺、量角器、三角板**（按屏幕校准），支持实时读数
- **随机点名、计时器、演示聚光灯、计算器**——一节课无需切换任何软件
- **无账号，不上传绘图、名单或日志**：默认自动检查更新，仅获取 GitHub 发布信息；下载和安装分别需要手动确认，不静默下载或安装。可在设置中关闭自动检查

当前版本 **v6.0.0**（已发布 Windows x64 便携版），界面支持 8 种语言（自动跟随系统）：中文、English（英语）、Français（法语）、Español（西班牙语）、Deutsch（德语）、Русский（俄语）、한국어（韩语）、日本語（日语）。

## 功能一览

### 批注与绘图
- 普通笔、钢笔、毛笔、书法笔、铅笔、蜡笔、粉笔、霓虹笔、虚线笔、彩虹笔、箭头笔，另有荧光笔与激光笔。
- 点击任意笔形直接打开设置；钢笔/毛笔可调起收锋与压感，书法笔可调角度与扁尖宽度，纹理笔可调覆盖率与浓度，霓虹可调光晕宽度与强度，虚线可调段长与间隔，彩虹可调变色速度与饱和度，箭头可调大小与张角。每种永久笔分别保存颜色、粗细、速度→笔宽和高级参数，并可一键重置；参数从下一笔生效，已有笔迹不变。
- 主栏「批注」和笔形按钮内嵌当前颜色圆点，不增加主栏尺寸。彩虹笔显示彩色圆点。
- 停笔定形仅用于普通笔，避免把特殊笔形自动改成标准图形。
- 荧光笔（颜色、粗细、透明度可调）；激光笔只指示不落墨。
- 导出限制：PNG/PDF 保留纹理效果；SVG 中铅笔/蜡笔/粉笔降级为同色半透明实线；EPS 无透明合成，纹理笔为实线、霓虹仅保留中心线，书法笔保留扁尖轮廓、虚线保留段长/间距。
- 橡皮（圆形擦 / 线条擦）
- 图形工具：直线、虚线、三角形、矩形、平行四边形、梯形、菱形、圆、椭圆、角
- 立体图形：正方体、长方体、圆柱、圆锥
- 框选 / 点选，复制、删除、移动、缩放、旋转，撤销 / 重做

### 智能功能
- **停笔定形**：手绘画完，笔停在末端约 0.6 秒即转成标准图形（笔尖有进度环提示）；在进度环完成前抬笔则保留手绘
- 连画 3 段共线短线自动合成虚线
- 直线端点自动吸附
- 几何辅助构造：外接圆、内切圆、中线、高、对角线、角平分线等

### 白板
- 多页管理，紧贴翻页条的紧凑缩略图列表。
- 首页／末页的翻页箭头置灰，点击提示「此是第一页／此是最后一页」。
- 在列表中选中页面后，点击底部红色「删除」按钮，二次确认默认取消；删除唯一一页后保留一张空白页。
- 黑 / 白板切换
- 逐页导出 PNG / PDF / SVG / EPS（多页导出带页码；SVG/EPS 为矢量，可再编辑）

### 课堂工具
- **测量教具**：真实毫米/厘米直尺、45°/30° 三角板、实时读数量角器（可移动、旋转、调整量程）
- **随机点名**：导入 txt/csv 名单，抽中结果大字全屏投影展示
- **计时器**：正计时 / 倒计时，到点响铃 + 红色闪烁
- **放大镜**、**演示聚光灯**（暗化全屏、亮区跟随鼠标）
- 计算器
- 文字与公式：拖拽定框、多行输入、可改色/粗细/旋转；结构化公式编辑器支持分数、上下标、根号、求和、积分（点哪个格子就在哪输入）。字母数字用系统触摸键盘，符号面板另按类型折叠在键盘上方

### 导入 / 导出
- 导入图片或 PDF（图片与 PDF 页面以 base64 内嵌进项目文件，**单文件自包含**，可分享可备份）
- 导出 PNG / PDF / SVG / EPS
- 支持把 `.msd` / `.json` 项目文件**拖到主面板**直接打开

### 设置与外观
主栏「设置」按钮打开设置页，分外观 / 界面 / 绘制 / 系统 / 关于五段：

- 统一使用图标式工具栏；主栏模式按钮显示为「鼠标」
- 鼠标模式下隐藏批注工具和白板控制，只保留鼠标、批注、设置、关闭等基础入口；点击「批注」恢复绘图模式并展开完整批注菜单
- **界面透明度** 35%–100%：只作用于操作面板，**画布和墨迹永远不透明**（否则就是画的东西变浅，不是界面变透）
- **圆角** 0–24px：面板、按钮、子面板、菜单、滑块一起跟随
- 亮 / 暗主题、主面板横竖版、智能图形识别、多指同时书写、速度→笔宽，都收在这里
- **开机自动启动**（默认关闭）：写当前用户的注册表 Run 项，关掉即删除。绿色版换了目录后会自动纠正路径
- **更新频道**：选择正式版或预览版；默认自动检查更新，也可手动检查或关闭自动检查
- **应用内更新**：发现新版本后，在应用内确认下载和安装；安装会保留 `data/`、`exports/`、配置、自动保存、名单和日志

#### 设置 → 绘制：换页后落笔恢复批注笔

- **换页后落笔恢复批注笔**默认**开启**。白板实际换页后，若当前处于橡皮、选择、图形等非批注状态（或鼠标模式），下一次画布左键按下／触控开始先恢复上次批注工具，再继续处理同一次接触，**无需再点一次，首笔不会因自动切换丢失**。
- 恢复范围包括具体永久笔形、荧光笔和激光笔；激光笔恢复后仍只指示，不留下永久笔迹。已经处于批注笔状态时不强制切换。
- 上／下页、缩略图跳页、新建页，以及删除当前页后切到保留页（删除唯一页则留下空白页）会进入该逻辑。点击首页／末页边界、当前页缩略图，或只删除其他页，不会新增一次待恢复动作。
- 换页后主动选择工具（包括再次选择当前工具）、切换鼠标／绘图模式、退出白板或关闭此开关，会取消待恢复动作。仅打开设置不会取消；白板外的鼠标穿透行为不变。

#### 设置 → 绘制：使用自定义笔预设

- **使用自定义笔预设**是唯一总开关，默认**关闭**，没有每支笔各自的开关。关闭时沿用最后使用设置；关闭不会删除预设，也不会撤回已经应用到当前配置的值。
- 在总开关下方的 **笔型** 中选择目标笔：11 种永久笔形各有独立的颜色、粗细、速度变宽及适用的高级参数，书法笔另有笔尖角度；荧光笔保存颜色、粗细、透明度，激光笔保存颜色和粗细。总开关关闭时也可编辑和保存。
- **手动编辑**：选笔型、点击色块使用支持透明度的调色盘、确认颜色，再点 **保存预设**。色号只读，可查看与复制；取消调色盘不改变草稿。仅编辑或切换下拉框不会保存到配置，也不会切换画布工具。未设置的预设使用内置默认值，不会自动捕获最后使用配置。
- **保存现用配置**：先在普通笔设置中调好目标笔，再到此处选择同一笔型，点 **捕获当前**。该按钮直接把编辑器所选笔型的当前配置保存为预设，并替换该笔型的编辑草稿；不是捕获任意当前活动工具，也不需要再点保存。
- 开启后，在启动恢复设置、从其他工具或笔形切回时加载对应预设；打开总开关时，若当前工具为批注笔，也会立即应用。换页自动恢复到另一批注工具时同样遵循此规则。重复点击已选中的同一支笔只打开设置，不重载预设；不会每一笔都重置。
- **保存预设**或**捕获当前**本身不立即应用。需要查看新预设效果时，保持总开关开启，切到另一工具／笔形再切回。普通笔设置中的临时调整不会覆盖预设；以后重新加载预设时才覆盖临时值。所有这些操作只影响后续绘制，**不修改已画笔迹**。

旧配置缺少新增字段时，换页恢复默认开启、自定义预设默认关闭，提醒从首次正常启动计数；已有独立笔形配置继续保留。已发布的正式包通过上述无屏自动化校验；视觉、真实输入、物理触屏与完整的整包升级验收仍待完成。

## 使用说明

### 测量教具校准（重要）
第一次使用直尺前，建议先校准：
「工具 → 辅助作图 → **校准当前屏幕**」，用实体直尺对齐校准窗口的两个端点。校准按显示器分别保存；未校准时使用系统 DPI 估算值。

- 直尺每个小刻度 1 mm、主刻度 1 cm；鼠标悬停尺身可实时读取 mm/cm
- 滚轮或橙色圆形手柄调整尺子**量程**（不改变每毫米实际间距）；拖动紫色方块或 `Ctrl + 滚轮` 调整尺身**宽度**
- 量角器：圆心对准角的顶点、水平基线对准角的一边；悬停半圆内实时读数，按住 Shift 吸附整度
- 教具可拖动本体移动、拖青绿色手柄旋转、**右键移除**

### 鼠标与批注模式
点击「鼠标」后，鼠标/触控会穿过画布直接操作下层软件，工具栏收缩为基础按钮；点击「批注」恢复绘图并显示完整批注菜单。切换时已画内容不会丢失。

### 项目文件与自动保存
- 「工具 → 打开 / 保存」管理 `.msd` 项目文件（含白板所有页面）
- 程序每 30 秒自动保存；异常退出后下次启动会询问是否恢复
- 主动保存才可靠，自动保存仅用于意外恢复

### 便携包校验与手动升级
下载同一 Release 的 ZIP 和 `.zip.sha256`，在 PowerShell 中计算：

```powershell
Get-FileHash -Algorithm SHA256 .\MyScreenDraw-v6.0.0-windows-x64.zip
```

将结果与 `.sha256` 文件中的值比较。正式退出旧程序后，备份 `data/`、`exports/` 和另存到其他位置的项目文件；将新包完整解压到新目录，再按需要复制备份数据。不要同时运行两个版本操作同一份数据。自动保存不是版本备份。

自 beta.8 起，旧版共用的笔颜色、粗细和速度变宽设置会迁移为每种笔的独立配置；6.0.0 保留该迁移逻辑。迁移后修改一种笔不会同步修改其他笔。旧版程序不保证完整保留新笔形效果，回退版本前请保留原始项目与数据备份。

## 常见问题（FAQ）

**Q：Windows 提示「Windows 已保护你的电脑」/ 杀毒软件报警？**
A：发行版尚未提供代码签名，可能触发 Windows 的信誉警告；这不等于已确认恶意，也不能据此保证安全。请核对下载来源、校验 SHA-256，并结合安全软件检查；不要仅因程序开源就忽略警告。程序默认自动检查更新，但不会上传绘图、名单或日志。需要离线使用时，请关闭设置中的自动检查更新，且不要手动检查或下载；严格隔离环境应在首次启动前通过防火墙阻止出网。

签名有助于识别发布者，但不能保证消除 SmartScreen 或杀毒软件告警。SHA-256 只用于完整性核对，不是数字签名。也可以按 [贡献指南](CONTRIBUTING.md) 从源码构建；具体信任边界见 [代码签名说明](docs/code-signing.md)。

**Q：数据保存在哪里？**
A：程序目录下的 `data/`（配置、自动保存、点名名单、本地日志）和 `exports/`（导出文件）。备份时请连同 `data/` 一起备份。

**Q：支持多显示器吗？**
A：画布固定在主屏幕；工具栏可在各屏幕间拖动，直尺校准按显示器分别保存，截图/导出可指定目标屏幕。

**Q：EPS 导出后中文显示不全？**
A：EPS 是矢量 PostScript，使用标准字体，不含中文字库的查看器可能缺字。需要矢量且含中文请用 SVG。

**Q：能同时两指/两人一起画吗？**
A：可以（v5.2.0 起）。批注笔和荧光笔支持多指同时书写，每根手指各写一笔、各自独立停笔定形，撤销按「笔完成的先后」逐笔回退。两指共用当前工具和颜色（不能一指画笔、一指橡皮）；选择、图形、文字、橡皮仍是单点操作。

## 隐私与数据安全

- **不上传绘图、名单或日志**。更新检查仅访问公开 GitHub release API（`api.github.com/repos/wcr20140908/MyScreenDraw/releases?per_page=30`）获取版本信息。当前版本新安装默认开启（自 beta.7 起），保留已有关闭设置；加载设置后每 24 小时检查一次，首次约在运行 24 小时后，不在启动时立即检查。可手动立即检查。发现新版只提示，下载和安装各自需要用户确认。
  - 下载在后台线程进行，不打开 GitHub 下载页面
  - 安装前会校验 ZIP，拒绝路径穿越、符号链接、重复条目、过大归档、过多成员和缺少 `MyScreenDraw.exe` 的归档
  - 安装过程跳过 `data/`、`exports/`、配置、名单、日志和自动保存，不覆盖现有设置与用户数据
  - 需要离线使用：关闭更新检查且不要下载更新；严格隔离环境应在首次启动前通过防火墙阻止出网
- **开机自动启动**（v5.5.0 起，默认关闭）：打开时会在 `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` 下写一条名为 `MyScreenDraw` 的值，内容是本程序的启动路径。关掉即删除该值。只涉及当前用户，不碰 `HKEY_LOCAL_MACHINE`，不需要管理员权限，此开关不修改其他注册表项。
- 本地日志（`data/events.jsonl`）可能包含文件名等信息，分享前请自行检查
- 点名名单（`data/roster.json`）含学生姓名，属个人信息，请勿随程序分发
