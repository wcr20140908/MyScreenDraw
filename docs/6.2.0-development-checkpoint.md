## 验证与发布记录

本版本分别完成离屏业务回归、独立教学进程、Windows 原生窗口输入、教学资源门禁、冻结便携包、ZIP/解压内容核对和公开附件校验。不同组合按各自范围记录，不将不同层级重复累计为单一数字。

橡皮 CPU 基准仍以 21,600 段和 21 次真实移动事件作为可复查性能场景，修复后实际擦除中位数 19.45 ms、P95 25.16 ms，空擦中位数 0.175 ms；前后删除段数和输出像素保持一致。

2560×1440、175% 缩放环境的原生输入回归覆盖漫游、双指缩放、缩放后书写、多指书写、擦除、多列页面缩略图、跨行排序和立体图形隐藏棱；证据保留在私有目录，未进入仓库或发行包。

## 正式附件

- `MyScreenDraw-v6.2.0-windows-x64.zip`
- `MyScreenDraw-v6.2.0-windows-x64.zip.sha256`

正式包为 Windows x64 便携包，包内含离线教学资源及合成示例，不含用户数据、截图、日志或裸 Python 源码。包内清单、EXE 哈希、源码提交、校验和与公开 Release 保持一致。

## 使用边界

更多可交互棱柱/棱锥仍为只读调研，未实现。设置中的反馈入口已接入外部表单，由用户主动打开并决定是否提交内容。程序未使用代码签名，SHA-256 用于完整性核对，不等同于数字签名；EPS 受 PostScript 格式限制，中文字体和透明效果可能与屏幕显示不同。
