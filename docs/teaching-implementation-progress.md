C07 公式章节支持直接点击画布上的公式槽位和主行末尾定位光标，不依赖物理 End 键或系统屏幕键盘；输入框与画布光标保持同步，结构化编辑按真实槽位和内容变化推进。

## 已交付的验证与保护

- 教学进程链使用私有 QProcess 和业务操作，覆盖原工作挂起/恢复、文档及配置隔离、页面与项目状态保护。
- 教学结果按真实业务结果判定：新增笔迹、擦除、排序、漫游、公式结构、保存恢复、导入、导出及取消/部分结果均有对应状态语义。
- 多列缩略图支持极端页面完整显示、跨行拖动、边缘自动滚动、页面身份与内容保持，以及关闭后不被心跳重新显示。本次更新还支持单击保留列表、双击进入并关闭、明确的前后插入线，以及默认／自定义名称随页移动和保存重开保持；这些新增行为的实屏结果另行记录。
- 长方体和正方体保持九条可见实棱与三条隐藏虚棱；画布、预览、PNG/PDF/SVG/EPS 及缩略图沿用一致语义。
- 教学文字面板会避让公式样例、工具栏、菜单、选择面板、页面栏和屏幕键盘；普通编辑模式继续使用原有面板锚点。
- 发布资源门禁覆盖递归源码、精确教学资源清单、内容哈希和隐私拒绝规则；正式包只包含离线课程与合成示例，不包含用户数据、截图、日志或裸源码。
- Windows 原生输入验收使用独立进程、目标窗口核对和私有证据目录；截图和输入日志不进入源码、提交或发行包。

## 使用边界

更多可交互棱柱/棱锥仍未实现；设置中的反馈入口打开外部表单，由用户自行决定是否提交内容。桌面批注仍按原有屏幕坐标工作；白板漫游不等于让点击穿透到其他软件。EPS 受 PostScript 格式限制，中文字体和透明效果可能与屏幕显示不同。
