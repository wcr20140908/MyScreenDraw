### 已验证的交互和异常边界

- 只有当前步骤签发的真实操作结果能推进；取消、失败、过期结果、信息按钮或程序布置素材不能冒充实操成功。
- 多动作 sequence 在每次成功后切换当前目标与屏障白名单；JSON 的 `allowed_targets` 必须与 sequence 一一对应。
- 当前控件的真实 Qt 弹出菜单树按输入事件动态解析，激活后新增的子菜单也可操作；无关的本程序菜单仍受限制，未拥有的第三方窗口不受影响。相关测试明确把菜单归为 owned，避免通过“不拥有”分支误判。
- 目标消失或被禁用时暂停并解除屏障，最多两秒事件驱动尝试恢复；超时后保留重试、跳章、退出，不永久锁住软件。
- 暂停收起说明并解除屏障；恢复保留私有工作，不重新建立章节素材，旧操作上下文失效。手动暂停时跳章和退出也保持可达。
- 原生文件对话框的上下文管理支持嵌套和异常返回；暂时隐藏教学界面并移除屏障，但保留打开对话框前的真实操作上下文。整个真实文件操作及其终态 `emit_result` 必须放在该 context 内，避免选择器关闭原菜单后先触发目标丢失。此为离屏契约测试，**没有调用真实原生对话框验收**。
- 负坐标工作区、窗口移动、控件销毁重建、连续重播完成 100 次、重复关闭与置顶登记失败的清理已覆盖。
- Qt 呈现回调异常时停止学习判定并解除屏障；清理失败不能继续隐形接收成功结果。
- 新用户只在生命周期、恢复、布局和前台等条件全部安全时取得一次欢迎展示资格；手势、文字编辑、输入法、模态框、文件任务等忙碌条件只延后，不替用户结束操作。
- smoke、练习与自动化上下文不弹首次欢迎。接受/稍后/关闭分别记录，均不增加完成数；启动练习失败不撤回已接受决定。八语言欢迎控件均离屏加载真实词表。

### 审查发现及回归

只读子代理审查以离屏最小复现发现 1 个 P1 和 4 个 P2：回调中退出后流程继续、无语义 target 的 canvas 未监听、延迟 resolver 异常绕过清理、native dialog 返回几何异常遗留屏障、动态新增 submenu 被阻挡。主线程先补回归，观察到 11 项失败（包含额外的暂停跳章不可达、引擎启动回调停止后仍进入步骤），再逐项修复；另补 4 项注册器生命周期测试。

- 宿主 fixture/prepare/reveal/窗口管理/geometry/canvas 回调返回后检查启动或步骤快照；已经关闭、停止或换步骤的旧流程不得复活引擎、窗口、计时器或事件过滤器。
- `TargetRegistry.watch(extra_resolvers=...)` 用会话级 resolver 跟踪真实 fallback canvas，不注册遗留的永久语义 ID；unwatch 释放它们。
- 延迟解析异常先拆监听并通知 presenter 失败收尾，不把异常漏出 Qt slot；初始 resolver 中同步 close 也不会重新安装监听。
- 对话框返回重定位走同一失败收尾；先验证 geometry，再安装输入屏障。
- 实际菜单树由屏障在事件时动态核实，不能把旧的 popup 快照永久放行。

修复后的五模块组合：**226 passed**；随后完整定向组合为上述 **514 passed**。同一审查代理随后独立重跑原最小复现和 **28 个定向离屏测试**，确认原五项已修复，在这些改动的限定范围内未复现新问题。测试范围有重叠，不能相加。这些回归与限定复审不等于真实主程序接线或原生验收。

### 进度存储和恢复的修复

- **真正写入失败**：保留合法的内存进度，磁盘原文件不变，ACK 明确为 `persisted=false`；只显示一次非阻断保存警告。不能保证这种情况下跨重启保存成功。
- **初始未来 schema/未知或不可读状态**：不把拒绝的写操作变成内存完成记录；安全内存视图与原文件均保持不变。
- 首次欢迎在展示前做一次原子可写性确认；失败则不自动弹出，手动中心仍可用。该确认不会记录用户决定或章节完成。
- 练习子进程必须确认退出后才调用原工作恢复；恢复回调抛异常时进入 `restore_failed`，保留原 token，阻止新会话，不冒充 `stopped`。
- `restore_pending` 与 `retry_restore()` 提供显式、幂等的恢复重试，不自动无限循环。宿主实际恢复回调仍须支持以同一 token 重试。
- 在 `activating` 同步通知里停止会话后，不继续发送 activate 或安装激活计时器；在 suspend 回调中处理事件并导致子进程退出的情况也已覆盖。
