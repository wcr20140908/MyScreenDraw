## 这轮实际接通了什么

### 练习是真实软件副本，不是只有提示框

`D:\MyScreenDraw\teaching\application.py` 创建真实 `ControlPanel` 和 `DrawingCanvas`，绑定本会话私有目录。子进程先验证本会话私有根和身份、连接父通信，再初始化私有资源/隐藏界面；通信包接受身份和顺序校验。正式授权激活前不显示画布、分体工具栏或 LOGO，也不创建托盘或全局键盘监听。

实际打开、保存、导入、导出、配置、名单、自动保存、日志等入口做 canonical 检查，不只是更换文件选择器起始目录。异步自动保存在线程内重新检查路径；练习屏幕导出只使用合成画布，不能抓取真实桌面。

两步测试章节验证了真正的“提交笔画 → 写入项目”链路：落笔结果只在非空笔画增量提交后发出；保存结果只在原子项目写入成功后发出。取消或失败不完成步骤；多接触点使用各自操作上下文。测试资源全部在临时根，**未作为正式教程打包**。

### 原工作恢复与所有入口保护

`D:\MyScreenDraw\app_lifecycle.py` 记录本应用拥有的顶层窗口、geometry/window state/visibility、业务计时器与焦点；不改原文档、撤销/重做、选区、工具、dirty 或当前文件路径。教学协调器自身的 QObject 子树不属于原业务计时器，避免误恢复已经删除的 broker 计时器。

托盘与 F12 的隐藏/恢复路由到私有练习。退出/重启先要求停止练习，确认子进程不再运行并恢复原工作，再异步进入普通保存确认/重启；不得先保存原文档或先拉起第二个普通实例。恢复失败保留 token 和保护，显式重试；失败会撤销待执行的退出/重启，避免后来重试成功时突然退出。

首次欢迎和手动开始均等待当前编辑/手势/文件/更新/自动保存完成，不替用户提交或取消。教学期间更新检查/通知/下载完成仅保留有限元数据，真正验证/安装/退出接力延后到安全返回，恢复失败和退出确认期间不重放。

### 教学界面现在能正确收尾

中心支持本地化名称/稳定 ID 搜索、已完成/未完成筛选、真实课程完成数和继续学习定位。needs_review 不算已完成；搜索不会缩小课程总章节数。

实际宿主完成或跳过后保留明确的退出摘要，按钮可用于结束练习、回到原工作；跳过不计完成。`persisted=false` ACK 只触发一次可见的 plain-text 非模态警告，后续成功 ACK 不把该次未落盘事实隐藏。中心也显示只读状态警告；未知高版本状态不因此变成内存完成记录。
