- 文件是纯文本资源：无导入、无 HTML、无未填占位符；所有值均已完整展开，不依赖运行时生成文案。
- 教学步骤分为信息确认和真实业务操作。信息步骤由用户点击现有“下一步”确认；操作步骤只在对应真实业务结果发生后推进。章节 `done` 只确认本章，不自动换章或退出。用户可在教学中心换章，或点击“退出教学”回到原工作；跳过不计完成。

## 真实控件和事实边界

- 白板流程使用真实“进入白板”“退出白板”以及白板内的“黑板”“白板”板色切换。白板有页面；批注模式可透出桌面并在其上显示批注。本练习不抓取桌面，不要求外部程序或系统输入。
- 页面条位于右下角：`+` 新增页面，“上页”“下页”切换，页码打开真实缩略图。单击缩略图选中页面并保留列表；双击直接进入该页并关闭列表。缩略图面板通过真实重命名、当前页删除、页面复制控件操作，正式文案统一称“重命名”“删除”“复制”；删除取消是取消删除并保留页面的成功结果，不能写成删除成功。排序课仍使用单击 C 的步骤，保留列表以便随后拖动。
- 设置目标是现有“复制页面的插入位置”。实际八语言选项按 `i18n.py` 的事实使用：中文为“原页前面”“原页后面（默认）”“最前面”“最后面”，其它语言文案与资源值同步。复制始终以当时的当前页为来源，新副本自动成为当前页，内容一致且页面 ID 不同。
- 页面排序使用 `PageListWidget` 的内部排序逻辑：把缩略图拖到插入位置会改变页面模型顺序；它不是自由摆放图标。蓝色带白描边和端帽的插入线标明落点：单列显示在页面上方或下方，多列显示在左侧或右侧；缝隙按最近页面确定，边缘自动滚动时同步更新。看到目标前方的插入线后再松开，提示与实际排序共用落点计算。
- 页码计数条表示当前位置和总页数；默认“第…页”名称、自定义名称、页面身份和内容均随页面移动，名称不等于当前位置。例如把第19页移到第14页前，名称顺序为第13页、第19页、第14页、第15页，而不是按新位置重新命名。默认名使用既有 `name` 字段保存；旧空名称在首次载入或规范化时按原序补齐，新建页避开现存默认名称冲突。
- 换页、删除页会重置页面历史；删除页不能用“撤销”找回；若删除最后一页，软件保留一个新的空白页。本练习不删除最后一页。
- “换页后落笔恢复批注笔”只作说明：开启后，换页时若当前为非批注工具才进入待恢复状态，下一次落笔恢复上次批注笔；主动选工具会取消待恢复。本练习不要求硬件，也不修改原配置。
- 复制位置练习使用私有练习设置，原工作配置不变，样例页面不保存回原工作。该设置的语义与 C04 对象复制方向不同；本章不扩展跨章保存或自动连续复制的教学。

### 四次复制的来源和顺序必须准确

| 复制步骤 | 复制前的当前源页 | 真实位置值 | 复制后顺序 | 复制后当前页与页码 |
| --- | --- | --- | --- | --- |
| copy_before | B | before | A/P1/B/C | P1，2/4 |
| copy_after | P1 | after | A/P1/P2/B/C | P2，3/5 |
| copy_first | P2 | first | P3/A/P1/P2/B/C | P3，1/6 |
| copy_last | P3 | last | P3/A/P1/P2/B/C/P4 | P4，7/7 |

每次必须新增恰好一个 page_id，此 ID 与源页和全部已有页不同；旧页面保留、源页内容不变，新副本内容与本次源页一致。内容比较覆盖样例使用的笔迹、文字、图形和图片的实际内容，另行核对页面 ID、名称与插入位置；不能把副本的名称或内部版本字段当成要求与源页完全相等的页面内容。来源页面必须以动作发生前的当前 ID 记录，每次结束再把新副本作为下一次来源。

**类型：** 操作
