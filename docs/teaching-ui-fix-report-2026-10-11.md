## 窗口位置

控制条按当前 Qt 逻辑坐标中的可用工作区、步骤锚点、可见工具栏和展开面板寻找位置。优先避免面板遮挡，再避免步骤目标，按面板边缘、上方、下方和工作区边缘搜索；可用区不足时选择交叠面积最小的有界位置。仅原有控制条超过工作区时才缩小，不改用户工具窗的尺寸、主题或透明度。

实际宿主提供 toolbar、logo、menu、selection、page rail、settings、text、calculator、roster、thumbnail 和 mini timer 的可见顶层窗口矩形；画布与控制条自身不作为障碍。150ms 刷新只调整位置，缓存不变布局，不重新设置输入屏障或改变 step epoch。暂停、文件对话框、隐藏和关闭分别保留各自门禁。

布局代理在独立 Git worktree 一次性完成几何/呈现改动，交付 b48424c；三个写入文件为 teaching/widgets.py、teaching/presentation.py 和 tests/test_teaching_layout.py。其最终安全组合为231 passed、1 deselected；41项新增布局测试由主线在真实宿主中补做接入验证。代理此前误包含一次合成 QWidget.grab 测试，没有读取桌面或保存图片；主线最终组合明确排除此项。

## 窗口层级与输入

原因由本地排序链复现确认：教学控制条设置了 Qt 置顶标志，但原浮窗排序和原生 owner 重绑列表没有包含它；重排画布后控制条可能留在画布下面。它的 Qt 按钮本身仍能接收点击。

新增明确的教学窗口登记：控制条、中心、欢迎、提示及恢复消息在现有 owner/order 链中参与排序；输入窗口位于透明高亮之前。显示时通过原有 raise_floating 回调立即校正，心跳与模式切换继续审计。仍保留非模态、不主动激活，以及高亮的 WindowTransparentForInput 与 WA_TransparentForMouseEvents。

延迟校正使用弱引用并重新检查登记、SIP 对象、可见性、前后台、练习激活及挂起豁免。登记层级不授予挂起期间显示权限；隐藏、退出、取消登记或销毁后不会被旧回调再次抬起。原实屏截图未被提交到仓库。

## C01 课程接入中修复的实际流程

正式 C01 已有六章、24步、56个文案键×八语言和七份纯合成合法项目。独立材料与原工作分开；保存/重新打开固定 practice.msd，预置私有恢复版本为 autosave_teaching_core_files.json.gz。预览后取消返回，再重新打开执行恢复；直接恢复不会冒充预览返回。

文件取消后通过可信 reveal 恢复当前目标，不使同一步因菜单收起而错误暂停。白板进入、加页和翻页结果延后到外层 UI 更新完成后交付，避免下一目标尚未显示时误判失联。真正暂停后恢复通过新 epoch 的有界结果排队到下一轮事件循环；已在运行时调用恢复不计完成。

六章同一真实 QProcess 的串行验证发现私有换章的工具栏尺寸变化：从批注切换到白板后高度增加，旧精确快照无法复原。新增仅限活跃私有进程的尺寸重建方法，保持位置、可见性、状态、计时器和全部校验；原工作仍走原严格恢复方法，普通进程不能使用此豁免。
