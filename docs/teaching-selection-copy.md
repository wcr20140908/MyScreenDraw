# C04 正式文案与成功条件

基于已批准T7的select_move、transform、copy_delete三章，共19步。`teaching/selection_copy.py`提供43个键、344条八语言字符串；语言顺序为zh/en/fr/es/de/ru/ko/ja。本稿已接入正式JSON和i18n，验收证据见`docs/teaching-selection-delivery-2026-10-11.md`。

本章用私有笔迹练习单击选取、移动、缩放和旋转，用两个合法矩形图形练习框选、复制和删除。当前矩形框选针对图形/图片；笔迹/文字用单击选取，依据main.py的select_objects_in_rect及CHANGELOG已有说明。实际工具名为“框选”，复制/删除按钮文字为“复”/“删”，没有教不存在的控件。
