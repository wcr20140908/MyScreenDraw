## 范围与结果

GitHub Issue：#17。基于提交 170e3cfeab6e66861ef71c1dc9f8ddcd3142e206 的当前未提交源码；保留本轮前已有的计算器、更新提示、界面、教学等改动。本轮没有更新版本号、构建或发布 EXE。

“保留原图”默认开启，位于设置 → 项目与教学。开关立即生效，并保存到配置的 preserve_original_images 字段；旧配置缺失字段及非布尔值均回退开启。关闭状态能保存并重新加载。

开启时，所有已有和新导入的图片及 PDF 页面图像均免于点选、框选、移动、缩放、旋转、选择删除、复制、橡皮擦和清空。擦除与清空仍移除批注；只含原图时清空不新增撤销记录。关闭后恢复图片编辑、擦除和清空。整页和项目格式没有增加锁定字段，保存重开继续保留图片。

图片改为绘制在笔迹、图形和文本下方，避免不透明图像盖住批注；点选顺序同步对应实际叠放。屏幕、PNG／PDF／SVG 共用画布绘制，EPS 的独立绘制顺序同步修正。
