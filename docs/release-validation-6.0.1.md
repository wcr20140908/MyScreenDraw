## 4. 6.0.0 → 6.0.1 手动迁移（必须单独验证）

**6.0.0 运行中的更新器有下载/安装缺陷，新包不能追溯修复老代码。** 不将新版源码/安装器的成功结果外推为旧版应用内升级已修复。本次用户路径为正式 Release 下载、新目录解压和手动复制数据。

- [ ] 记录旧版正式包和新候选包身份、哈希；如是本地候选演练，明确不是公开附件验证。
- [ ] 从正式 6.0.1 Release 下载 ZIP 和同版校验文件并核对哈希（待发布后补齐）。
- [ ] 新建空目录解压全部程序文件；不覆盖旧目录或源码目录，不提前启动新 EXE。
- [ ] 保存并从托盘退出旧版，确认旧 PID 结束；隐藏到托盘不算退出。
- [ ] 备份后复制旧 `data/`、`exports/`，保留外部项目；不覆盖已有隐私文件，冲突逐项处理。
- [ ] 修改快捷方式和已启用的开机自启路径，确认指向新目录 EXE。
- [ ] 运行新 EXE，核对 v6.0.1、设置/项目/导出；完全退出再启动，并检查旧目录及备份仍可用于恢复。

实际步骤、执行环境、合成数据哈希、启动路径、版本与重启证据：**待父代理填写，未验证**。
