# 代码来源与许可证复核 / Provenance and license review

**当前记录基线：v6.0.0-beta.8；更新日期：2026-10-02。**

本页是工程清单与复核范围说明，不是法律意见，也不是已经完成全仓库、全部 Git 历史和所有依赖逐行审计的证明。此前 v5.4.0 的来源记录可在 Git 历史中查阅；其中旧文件规模、“无运行时下载”和“无版权头”等扫描结论不能直接用于当前版本。

## 当前模块与来源记录要求

项目代码包括主画布/控制面板、Windows 生命周期与工具栏、持久化、测量几何、公式、触摸键盘、图标、EPS 导出和测试；职责见 [架构说明](architecture.md)。新增或移植代码必须注明来源、许可和改动，保留需要保留的版权声明。

项目使用公开 Win32 API、Qt API 和常见几何/数值算法。使用公开算法或 API 不等于可以复制任意第三方实现；“没有找到复制标记或版权头”也不能证明代码原创或许可兼容。

## 依赖与分发资源

| 类别 | 当前记录与检查入口 |
| --- | --- |
| 项目许可 | `LICENSE`：GPL-3.0-or-later |
| 运行时直接依赖 | PyQt6、pynput；版本见 `requirements.lock` |
| 运行时传递依赖 | PyQt6-Qt6、PyQt6_sip、pywin32、six；不能只检查两个直接依赖 |
| 构建工具 | `requirements-build.lock`；打包还包含 PyInstaller bootloader 等运行组件，不能仅因工具属于构建期就忽略分发义务 |
| 第三方声明 | `THIRD_PARTY_LICENSES.txt`；升级依赖后需按实际包及其许可证复核 |
| 测试工具 | pytest、pytest-subtests；不在当前运行时/构建锁文件中 |
| 图标与公式 | 查看 `ui_icons.py`、`main.py`、`formula.py` 的绘制实现；新增资源单独记录来源 |
| 用户导入内容 | 项目中的图片/PDF、名单、截图不属于可随程序公开分发的默认素材 |

PyQt6 使用 GPL/商业双许可。项目按 GPL-3.0-or-later 分发不意味着任意依赖和任意二次分发方式都自动合规；需按具体组件确认许可与署名义务。

`MyScreenDraw.spec` 引入项目许可证与第三方声明，`build.ps1` 检查便携包中存在这两份文件，并排除用户数据和开发截图。最终附件仍须人工核对；检查文件存在不能替代内容审查。

## 待持续复核的范围

- [ ] 新增代码/资源的来源与许可，包括上游要求保留的声明。
- [ ] 升级后的直接/传递依赖、Qt 组件和打包运行组件的许可义务。
- [ ] 最终便携包许可证内容与实际分发文件是否一致。
- [ ] Git 全历史是否曾包含名单、配置、凭据或其他用户数据；当前 `.gitignore` 不能移除历史泄露。
- [ ] 公开截图、日志和项目样例已获授权并脱敏。

这些是持续检查项，不表示已经发现违规，也不表示本次文档更新已完成它们。

## 可复用的检查命令

在仓库根目录运行 PowerShell：

```powershell
# 初筛版权声明和来源标记；命中与否都需要人工解释
Select-String -Path *.py,tests\*.py -Pattern 'Copyright|SPDX|Licensed under|copied from|adapted from'

# 查看已跟踪文件；不显示文件正文
git ls-files
git log --all --oneline -- data/roster.json data/config.json
```

不要将零匹配写成“证明原创”，也不要将历史路径无命中写成“整个历史无敏感信息”。发现疑似泄露时停止公开传播，按 [安全策略](../SECURITY.md) 私密报告。
