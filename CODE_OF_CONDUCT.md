# MyScreenDraw Code of Conduct

## Our commitment

We want MyScreenDraw to be a welcoming, practical project for classroom educators,
users, and contributors of every background and experience level.

## Expected behavior

- Be respectful, constructive, and patient.
- Focus feedback on the code, documentation, and user experience rather than people.
- Give credit for ideas and report security issues privately as described in `SECURITY.md`.
- Keep contributions relevant to the project and suitable for a public educational tool.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, doxxing, sexualized conduct,
and knowingly submitting malicious or unauthorized content are not acceptable.

## Enforcement

Project maintainers may edit or remove contributions, close discussions, or restrict
participation when necessary to keep the project safe and constructive. Report concerns
privately through the security/reporting channel in `SECURITY.md` rather than posting
sensitive details publicly.

This document is adapted from the Contributor Covenant in spirit, but is intentionally
short so the project can state its practical expectations clearly.
